You are a senior ERP architect and full-stack engineer working on the MATERION system.

Your task is to implement a COMPLETE OCC TEMPLATE SYSTEM for industrial purchasing workflows.

DO NOT create a simple copy feature.

This must behave like a professional enterprise ERP system with reusable procurement templates, intelligent defaults, duplication workflows, and PDF template support.

All user-facing content MUST remain in Brazilian Portuguese (pt-BR).

==================================================
1. CREATE A NEW MODULE: OCC TEMPLATES
==================================================

Create a dedicated module called:

➡ "Templates de OCC"

This module must allow users to create reusable OCC models/templates.

==================================================
2. TEMPLATE TYPES
==================================================

Support TWO template modes:

==================================================
2.1 STRUCTURE TEMPLATE
==================================================

Template contains:
- fornecedor padrão
- CNPJ padrão da empresa
- observações padrão
- setor padrão
- categoria padrão
- prioridade padrão
- condições de pagamento
- prazo padrão
- layout do PDF
- assinatura/rodapé

NO items required.

Purpose:
Reusable structure only.

==================================================
2.2 FULL TEMPLATE WITH ITEMS
==================================================

Template contains EVERYTHING above PLUS:

- lista de materiais padrão
- unidades
- quantidades padrão
- observações por item
- fornecedor preferencial por item

Purpose:
Fast recurring OCC generation.

==================================================
3. NEW OCC CREATION FLOW
==================================================

When user clicks:

➡ "Nova OCC"

Show modal with:

- Criar do zero
- Criar a partir de template
- Duplicar OCC existente

==================================================
4. CREATE OCC FROM TEMPLATE
==================================================

When user selects:
➡ "Criar a partir de template"

System must:
- list all templates
- allow search/filter
- show preview summary

After selection:
- prefill OCC automatically
- allow editing before saving

==================================================
5. DUPLICATE EXISTING OCC
==================================================

Add feature:

➡ "Duplicar OCC"

This must:
- clone OCC structure
- clone items
- clone supplier
- clone observations
- clone company CNPJ
- generate new OCC number automatically

User can edit before saving.

==================================================
6. SAVE OCC AS TEMPLATE
==================================================

Inside OCC detail page:

Add button:
➡ "Salvar como Template"

Behavior:
- converts current OCC into reusable template
- user chooses:
  - template name
  - description
  - structure only OR full template with items
